## 한 줄로

**"이 운용사가 삼성전자를 얼마나 갖고 있지?"** 에 답하기 위해, 흩어져 있는 공개 자료를 매일 모아서 한 화면에 보여주는 프로그램입니다.

---

## 왜 필요한가요?

자산운용사는 남의 돈을 대신 굴려주는 회사입니다. 수조 원씩 굴리는 곳도 있습니다.

이런 회사가 삼성전자 주식을 많이 갖고 있다면, 증권사 입장에서는 **좋은 고객 후보**입니다. 삼성전자 리서치를 팔 수도 있고 주문을 받을 수도 있으니까요.

문제는 **어디에 얼마나 갖고 있는지 한 번에 알 방법이 없다**는 겁니다. 정보가 여러 나라, 여러 기관에 흩어져 있고 형식도 제각각입니다. 이 프로그램이 그걸 대신 긁어모읍니다.

---

## 어디서 모으나요?

| 무엇을 | 어디서 |
|---|---|
| 미국 주식 보유내역 | 미국 증권거래위원회(SEC) 제출 서류 |
| **한국 주식 보유내역** | 운용사가 직접 내는 **펀드 소개서(팩트시트)** |
| 한국 5% 이상 지분 | 금융감독원 DART 공시 |
| 운용 규모(AUM) | SEC 등록서류, 회사 홈페이지 |
| 임직원 | SEC 등록서류, 회사 팀 소개 페이지 |

---

## 가장 중요한 것 하나

이 프로그램을 쓸 때 **반드시 알아야 할 개념**이 하나 있습니다.

### 운용사는 보유 종목을 "전부" 공개하지 않습니다

펀드 소개서에는 보통 **상위 10~25개 종목만** 적혀 있습니다. 나머지는 안 적습니다.

실제 예시입니다. Mawer라는 운용사의 펀드를 보면:

```
펀드 전체 크기      약 7조 원
갖고 있는 종목      72개
소개서에 적힌 것    24개    ← 우리가 볼 수 있는 것
안 적힌 것          48개    ← 약 3조 원어치가 안 보임
```

### 그래서 이렇게 읽어야 합니다

> ✅ **"이 운용사는 삼성전자를 최소 이만큼 갖고 있다"** — 맞는 말
>
> ❌ **"표에 없으니 안 갖고 있다"** — **틀린 말**

시험 성적으로 비유하면, 반에서 **상위 5등만 발표**했을 때 6등인 친구가 "시험을 안 봤다"는 뜻은 아닌 것과 같습니다. 그냥 발표 목록에 없는 것뿐입니다.

영업하러 갈 때 "표에 없으니 안 갖고 있네" 하고 넘어가면, 실제로는 갖고 있는 고객을 놓칩니다. 화면 곳곳에 이 경고를 적어둔 이유입니다.

### 다만 크기는 짐작할 수 있습니다

안 보이는 종목이라도 **소개서에 적힌 가장 작은 종목보다 클 수는 없습니다.** 그보다 컸으면 목록에 들어갔을 테니까요. 위 예시에서는 그 기준이 약 1,600억 원입니다. 즉 "1,600억 원어치를 갖고 있는데 우리가 놓쳤다"는 일은 생기지 않습니다.

## 왜 이렇게 만들었나 (규칙 3개)

### 1. 한번 모은 자료는 지우지 않습니다

수정된 공시가 와도 **덮어쓰지 않고 새로 추가**합니다. "그때 우리가 알던 내용"을 나중에도 확인할 수 있어야 하니까요.

### 2. 모르는 건 비워둡니다

회사를 식별하는 번호를 모르면 **비워둡니다. 추측해서 넣지 않습니다.**

비워두면 화면에 "설정 안 됨"이라고 나옵니다. 하지만 번호를 **잘못** 넣으면 엉뚱한 회사 자료가 이 회사 이름으로 올라오는데, **화면상으로는 아무 문제가 없어 보입니다.** 나중에 알아채기가 훨씬 어렵죠.

### 3. "없다"와 "모른다"를 구분합니다

- 자료를 아직 못 받은 것 → **"미수집"**
- 받았는데 한국 종목이 없는 것 → **"없음"**

둘은 완전히 다른데 화면에서는 똑같이 "빈 표"로 보이기 쉽습니다. 그래서 항상 구분해서 표시합니다.

같은 이유로, 프로그램이 자료 형식을 못 알아보면 **조용히 "0개"라고 하지 않고 오류를 냅니다.** 조용히 넘어가면 "이 운용사는 한국 주식이 없구나"로 잘못 읽히니까요.

## 알아둘 한계

- **한국 보유내역은 "최소한 이만큼"입니다.** 위에서 설명한 이유입니다.
- **사모펀드는 아예 안 나옵니다.** 공개 의무가 없어서 어떤 무료 자료에도 없습니다.
- **미국 서류에는 삼성전자가 절대 안 나옵니다.** 삼성전자는 미국 증시에 상장돼 있지 않기 때문입니다.
- **Burgundy의 미국 보유내역은 2025년 9월에서 멈춰 있습니다.** 그 뒤로는 Bank of Montreal이 합쳐서 신고하는데, 합친 자료에서 Burgundy 몫만 떼어낼 수 없습니다. 운용 규모(AUM) 정보는 계속 갱신됩니다.

## 실행해 보기

```bash
pip install -e '.[dev]'
export DATABASE_URL="postgresql://postgres:postgres@localhost:5432/burgundy"
export SEC_USER_AGENT="burgundy-tracker 본인이메일@example.com"

python -m db.migrate     # 데이터베이스 준비
python -m pipeline.run   # 자료 수집 1회
uvicorn dashboard.app:app --reload   # http://localhost:8000
```

> 데이터베이스(PostgreSQL)를 먼저 켜두세요. 없으면 **테스트 절반이 조용히 건너뛰어서**, 통과한 것처럼 보이지만 실제로는 안 돌아간 상태가 됩니다.
